Este Módulo Técnico 08 se enfocó en la tecnología de fabricación sustractiva, manufactura CAD-CAM aplicada al 'Control numérico computarizado ~ CNC', a partir de un abordaje mayormente teórico-digital antes que práctico, dado el tiempo destinado disponible para una tecnología de fabricación exigente en tiempo y técnica de maquinado y que demandan ineludiblemente amplia presencialidad real de práctica para lograr ensayos y errores iterativo reales.

El proceso curricular pautado para la fabricación tecnológica en CNC se centró en el uso de Fusion 360 CAM ~ Módulo Fabricación (sección técnica digital CAD de seteo y simulación del maquinado CNC dentro del software), para el setting y generación del archivo CAM en router CNC. 

Este potente módulo dentro de Fusion 360, nos permite realizar todo tipo de operaciones de mecanizado y guardarlas en un código G (archivo CAM). El código G para poder operar el Router CNC es de extensión .nc . Dentro de éste módulo exploré las principales operaciones de la Interfaz para lograr realizar un archivo .nc

## **REFLEXIONES** . MT08
# ❝ 
El Router CNC comparativamente a las tecnologías de fabricación previas exploradas en las prácticas es de las más demandantes en el seteo de parámetros y secuencia de pasos de mecanizado. Fusión/fabricación como software permite una compresión integral paso a paso del proceso de maquinado CNC. Ofrece un realismo de simulación útil permitiendo mitigar errores, previo al prototipado CAM CNC. Al mismo tiempo, exige un proceso tedioso, extenso en setting de variables a diferencia de Easel, de un uso intuitivo y ágil para el setting y simulación del prototipado de proyecto (aunque completo solo en su versión premium); En este sentido queda bastante por explorar aún, para visualizar un punto intermedio práctico de la herramienta de Setting digital compatible con las dinámicas ágiles del hacer profesional fuera del contexto “romántico” del entorno de aprendizaje.
